# Shibakamio2026 — 学生向け家計簿アプリ

収入・支出・資産（現金や口座）をまとめて管理できる、Web ブラウザで使う家計簿アプリです。

## このアプリでできること

「お金がいくら入って、何に使って、今どこにいくら残っているか」を記録して、ひと目で確認できるようにするアプリです。

学生のお金の管理には、次のような面倒があります。

- 財布の現金、銀行口座、PayPay など、**お金の置き場所がいくつもある**
- スマホ代やサブスクなど、**毎月決まって出ていくお金**を毎回入力するのが手間
- PayPay で払った分を、**1 件ずつ手で打ち直す**のが大変

このアプリは、これらを減らすための機能を持っています。

## 主な機能と、その機能がある理由

| 機能 | できること | なぜ必要か |
| --- | --- | --- |
| ユーザー登録・ログイン | 自分専用のアカウントで使う | 家計簿は個人情報なので、他の人に見られないようにするため |
| 収支の記録 | 収入・支出を登録・一覧・編集・削除 | 家計簿の基本。入力ミスを後から直せるようにするため |
| 資産管理 | 現金・銀行口座・電子マネーなどを登録し、残高を表示 | お金の置き場所ごとに「今いくらあるか」を把握するため |
| 資産間の振替 | 「口座から財布へ 1 万円」などの移動を記録 | ATM で下ろしたお金は支出ではないので、収支と分けて記録するため |
| カテゴリー管理 | 「食費」「交通費」などを追加・編集 | 何にいくら使っているかを分類して振り返るため |
| 自動登録（固定費） | 毎週・毎月・毎年の決まった収支を登録すると、予定が自動で作られる | 毎回同じ内容を手入力する手間をなくすため |
| 予定の確定・キャンセル | 自動で作られた予定を確認して「確定」すると実際の記録になる | 金額が変わったり、その月だけ無かったりすることがあるので、勝手に記録せず本人が確認できるようにするため |
| PayPay CSV 取り込み | PayPay の取引履歴ファイルを読み込み、確認してからまとめて登録 | キャッシュレス決済の分を 1 件ずつ打ち直す手間をなくすため |
| カレンダー | 日ごとの収支をカレンダーで表示 | 「いつお金を使ったか」を直感的に見られるようにするため |
| レポート | 月ごとの収支、カテゴリー別の集計をグラフで表示 | 使いすぎている月や項目に気づけるようにするため |

### 細かい工夫

- **使用中のカテゴリーは削除ではなく「無効化」**
  すでに記録で使われているカテゴリーを消すと、過去の記録の分類がわからなくなります。そのため、使われている場合は削除せず、今後選べないようにする「無効化」にしています。資産も同じ考え方です。
- **資産ごとに「今の残高」と「予定を反映した残高」を表示**
  まだ確定していない固定費の予定も含めて、「この先いくら残りそうか」がわかるようにしています。
- **月末の日付への対応**
  「毎月 31 日」の固定費は、30 日までしかない月には月末の日付で予定を作ります。
- **パスワードは暗号化（ハッシュ化）して保存**
  データベースの中身を見られても、パスワードそのものはわからないようにしています（BCrypt を使用）。

## 使用技術と、選んだ理由

| 分類 | 使用技術 | 選んだ理由 |
| --- | --- | --- |
| 言語 | Java 21 | 学校で学んでいる言語で、Web アプリ開発の現場でも広く使われているため。21 は長期サポート（LTS）版 |
| フレームワーク | Spring Boot 4.1 | Java で Web アプリを作るときの定番。ログイン機能やデータベース接続などを少ない設定で使えるため |
| 画面 | Thymeleaf | HTML にデータを埋め込んで画面を作れる。普通の HTML に近い書き方ができ、学びやすいため |
| ログイン | Spring Security | ログイン・ログアウトやページごとのアクセス制限を、安全な方法で実装できるため |
| データベース操作 | Spring Data JPA | SQL を毎回書かなくても、Java のクラスとしてデータを保存・取得できるため |
| 入力チェック | Spring Validation | 「金額が未入力」「マイナスの金額」などの入力ミスをまとめてチェックできるため |
| データベース | PostgreSQL | 無料で使えて信頼性が高く、集計などの SQL も得意なため |
| ビルド | Maven | 必要なライブラリを自動でダウンロード・管理してくれるため。Maven Wrapper（`mvnw`）を同梱しているので、Maven を別途インストールしなくても動く |
| その他 | Lombok | getter / setter などの決まりきったコードを自動生成し、コードを短く読みやすくするため |

## プログラムの構成

役割ごとにフォルダを分けています。
**「画面とのやりとり」「処理のルール」「データの保存」を分けておくと、どこに何が書いてあるかがわかりやすく、修正したときに他の部分へ影響しにくい**ためです。

```
src/main/java/com/example/shibakamio2026/
├── controller/   # 画面からのリクエストを受け取り、表示する画面を決める（受付係）
├── service/      # 残高の計算、CSV の読み込み、固定費の予定作成など、処理のルールを書く（担当者）
├── repository/   # データベースへの保存・取得を行う（倉庫係）
├── entity/       # データベースのテーブルと対応するクラス（User, Asset, Transaction など）
├── dto/          # 画面の入力フォームや表示用にデータをまとめたクラス
├── enums/        # 決まった選択肢（収入/支出、現金/銀行口座 など）
├── config/       # ログインまわりの設定
├── exception/    # このアプリ独自のエラー
└── web/          # ログイン中のユーザーを取得するなどの共通処理

src/main/resources/
├── templates/    # 画面の HTML（Thymeleaf）
├── static/css/   # 画面の見た目（CSS）
├── schema.sql    # テーブルを作る SQL（起動時に自動実行）
├── data.sql      # お試し用データを入れる SQL（起動時に自動実行）
└── application.properties  # データベースの接続先などの設定
```

処理の流れは次のようになります。

```
ブラウザ → controller → service → repository → データベース
```

## データベースのテーブル

| テーブル | 保存する内容 | 分けている理由 |
| --- | --- | --- |
| `users` | ユーザー | 誰のデータかを区別するため |
| `assets` | 資産（現金・銀行口座・電子マネー・その他） | 置き場所ごとに残高を計算するため |
| `categories` | 収支のカテゴリー | ユーザーごとに自由に追加・変更できるようにするため |
| `transactions` | 実際の収入・支出 | 家計簿の中心となる記録 |
| `transfers` | 資産間の移動 | 収入・支出とは性質が違う（全体のお金は増えも減りもしない）ため |
| `auto_transactions` | 固定費の「ルール」（毎月 25 日に 3,000 円 など） | ルールと、そこから作られる 1 回ごとの予定を分けて管理するため |
| `scheduled_transactions` | ルールから作られた 1 回ごとの予定 | 「予定」「確定」「キャンセル」の状態を 1 回ずつ持たせるため |

## 自分のパソコンで動かす手順

このアプリは、自分のパソコンの中でサーバーを起動し、ブラウザから開いて使います。
ここでは **Mac で、初めてこのアプリを動かす人** を想定して、手順を順番に説明します。

> コマンドはすべて Mac の「ターミナル」アプリに入力します。
> （Finder →「アプリケーション」→「ユーティリティ」→「ターミナル」）

### 手順 1. 必要なソフトを入れる

アプリを動かすには、次の 2 つが必要です。

| ソフト | 何に使うか |
| --- | --- |
| **JDK 21** | Java で書かれたこのアプリを動かすため |
| **PostgreSQL** | 家計簿のデータ（ユーザー、収支、資産など）を保存するため |

ここでは [Homebrew](https://brew.sh/ja/) を使った入れ方を紹介します。
Homebrew は Mac 用のソフト管理ツールで、**コマンド 1 行でインストールでき、手順を文章で正確に伝えやすい**ためです。

```bash
brew install openjdk@21
brew install postgresql@16
brew services start postgresql@16   # PostgreSQL を起動する
```

PostgreSQL のバージョン（16）は一例です。特別な機能は使っていないので、他のバージョンでも動きます。

入ったかどうかは、次のコマンドで確認できます。バージョン番号が表示されれば OK です。

```bash
java -version
psql --version
```

### 手順 2. ソースコードをダウンロードする

GitHub からこのリポジトリを自分のパソコンにコピー（クローン）します。

```bash
git clone git@github.com:Shibakamio2026/Shibakamio2026.git
cd Shibakamio2026
```

2 行目の `cd` で、ダウンロードしたフォルダの中に移動しています。
以降のコマンドは、`mvnw` などのファイルがあるこのフォルダの中で実行する必要があるためです。

### 手順 3. データを保存する場所（データベース）を作る

アプリがデータを保存するための、空のデータベースを 1 つ作ります。

```bash
createdb shibakamio2026
```

名前は必ず `shibakamio2026` にしてください。
設定ファイルに「`shibakamio2026` という名前のデータベースに接続する」と書かれているためです。

作るのは「空の入れ物」だけで大丈夫です。
**テーブルやお試し用データは、アプリの起動時に `schema.sql` と `data.sql` から自動で作られます。**
どちらも「まだ無い場合だけ作る」書き方になっているので、何度起動してもデータが消えたり、二重に登録されたりはしません。

> **うまくいかないとき**
> アプリは、ユーザー名 `postgres`・パスワード `postgres` でデータベースに接続する設定になっています。
> 自分の PostgreSQL の設定と違う場合は、`src/main/resources/application.properties` の次の行を書き換えてください。
>
> ```properties
> spring.datasource.username=postgres
> spring.datasource.password=postgres
> ```

### 手順 4. アプリを起動する

ターミナルで次のコマンドを実行します。

```bash
./mvnw spring-boot:run
```

初回は必要なライブラリをインターネットからダウンロードするため、少し時間がかかります。
ログに `Started Shibakamio2026Application` と表示されたら起動完了です。

**Eclipse を使う場合**は、コマンドの代わりに
`Shibakamio2026Application.java` を右クリック →「実行」→「Spring Boot アプリケーション」でも起動できます。

止めるときは、ターミナルで `control` + `C` を押します。

### 手順 5. ブラウザで開いてログインする

ブラウザで次のアドレスを開くと、ログイン画面が表示されます。

👉 http://localhost:8080/login

`localhost` は「自分のパソコン」、`8080` はこのアプリが使っている番号（ポート）という意味です。

すぐに動作を試せるように、**お試し用のアカウントが最初から用意されています**。
自分でユーザー登録しなくても、次の情報でログインできます。

| メールアドレス | パスワード |
| --- | --- |
| `test@example.com` | `password123` |

このアカウントには、カテゴリー「食費」と資産「財布（1 万円）」が登録済みです。
自分用のアカウントを作りたい場合は、ログイン画面から新規登録してください。

## PayPay CSV の取り込みについて

PayPay アプリからダウンロードできる取引履歴ファイル（CSV）を読み込めます。

| ルール | 理由 |
| --- | --- |
| 文字コードは UTF-8 | 日本語（店名など）が文字化けしないようにするため |
| 1 行目は読み飛ばす | 1 行目は「取引日」「出金金額」などの見出しで、取引データではないため |
| 取引日は `2026/09/15` の形式 | PayPay の CSV がこの形式で出力されるため |
| 内容に「チャージ」を含む行は **チャージ** として扱う | チャージは口座から PayPay へのお金の移動で、支出ではないため |
| 出金額がある行は **支出**、それ以外は **収入** の候補にする | 自動で分類して、入力の手間を減らすため |
| 登録前に **プレビュー画面** で確認する | 自動の分類が間違っていることもあるので、登録前に本人が確認できるようにするため |
| ファイルサイズは 5MB まで | 大きすぎるファイルでサーバーに負担がかかるのを防ぐため |
